# Awesome Free AI Tools

A curated list of genuinely free AI tools and APIs. No credit card required, no trial traps.

## ⭐ Featured

- [FreeLLM](https://freellm.net) — Free LLM API with 487 models across 30 providers. No credit card required, one-click setup for Claude Code, Cursor and Codex.
- [MyToolster](https://mytoolster.com) — 50+ free online tools that run in your browser, no signup. Including AI text/image detectors, background remover, audio/video to text.
- [PhotoTextEdit](https://phototextedit.com) — Fix text in AI-generated images without regenerating. AI-powered image text repair, free online.

## More free AI tools

- [Hugging Face Spaces](https://huggingface.co/spaces) — Host and discover thousands of free community-built ML demos and AI apps.
- [Pollinations.ai](https://pollinations.ai) — Free and open AI API for text and image generation. No signup or API key required.
- [Ollama](https://ollama.com) — Run open-source large language models locally on your own machine, free forever.
- [LM Studio](https://lmstudio.ai) — Discover, download, and run local LLMs with a simple desktop app.
- [Duck.ai](https://duck.ai) — DuckDuckGo's free, private AI chat with access to multiple models.
- [Google AI Studio](https://aistudio.google.com) — Free access to Gemini models and API with a generous free tier.
- [Poe](https://poe.com) — Chat with many AI models in one place, with a free plan.
