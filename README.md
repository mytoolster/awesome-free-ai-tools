## ⭐ Featured

Tools we build and use every day — free, no signup.

- [FreeLLM](https://freellm.net) — Free LLM API with 487 models across 30 providers. No credit card required, one-click setup for Claude Code, Cursor and Codex.
- [MyToolster](https://mytoolster.com) — 50+ free online tools that run entirely in your browser, no signup. Includes AI text detector, AI image detector, background remover, audio/video-to-text.
- [PhotoTextEdit](https://phototextedit.com) — Fix garbled text in AI-generated images without regenerating. AI-powered image text repair, free online.

## 🤖 Free LLM APIs

- [FreeLLM](https://freellm.net) — 487 free models, 30 providers, OpenAI-compatible API.
- [Pollinations.ai](https://pollinations.ai) — Free and open AI API for text and image generation. No signup or API key required.
- [Google AI Studio](https://aistudio.google.com) — Free Gemini API with a generous free tier.

## 💬 AI Chat

- [Duck.ai](https://duck.ai) — DuckDuckGo's free, private AI chat with multiple models.
- [Poe](https://poe.com) — Chat with many AI models in one place, free plan available.
- [HuggingChat](https://huggingface.co/chat) — Open-source chat UI by Hugging Face, free.

## 🎨 Image Generation & Editing

- [PhotoTextEdit](https://phototextedit.com) — Repair text in AI-generated images, free online editor.
- [Pollinations.ai](https://pollinations.ai) — Free text-to-image API, no key needed.
- [MyToolster Background Remover](https://mytoolster.com) — Free AI background removal in the browser.

- [만화 번역기 AI](https://www.mangatranslate.com/ko/ai-manga-translator/) — 만화 번역기 AI는 100개 이상의 언어와 모든 지원 번역 언어로 개인 사용자의 일괄·맞춤 번역을 처리하며, 기업급 만화 번역기·리더로서 스튜디오에 완전한 온라인 Photoshop 스타일 편집기를 제공하고 API로 개인 작업 흐름을 연결합니다. 무료 사용자는 일일 체크인으로 제한된 크레딧을 받을 수 있으며, 추가 크레딧과 구독은 유료입니다.
